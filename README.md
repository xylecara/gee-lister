# Gee Lister

A todo list cli program that tracks your tasks with status values.

## Features

* Add and delete tasks with names and descriptions
* ID based listing system
* Status values to determine whether a task is idle, in progress, or done

## Installation

Currently there is no official installation yet but you could take the code and compile it yourself.

## Usage

The program can be used like this:
```
glister [commands]
glister [commands] [arguments]
glister [commands] [subcommand]
glister [commands] [argument] [subcommand] [argument]
```

Here is an example that lists all the tasks you have:
```
bash
$ glister list
```

If you have any difficulties with the program, use `glister help` or `glister [command] help`
